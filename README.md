# Homebrew tap for spill

Homebrew formulae for [spill](https://github.com/randallyash/spillover) — an
agentic terminal UI that runs your local model first and spills over to the next
tier when it loops, stalls, or fails.

## Install

```sh
brew install randallyash/spillover/spill
```

Or tap first, then install:

```sh
brew tap randallyash/spillover
brew install spill
```

## Upgrading

```sh
brew update
brew upgrade spill
```

## About this repository

The formula here, `Formula/spill.rb`, is generated by
[cargo-dist](https://opensource.axo.dev/cargo-dist/) and pushed automatically
when a release is tagged in the main repository. Please do not edit it by hand —
a change here is overwritten by the next release.

Anything else about spill belongs in the
[main repository](https://github.com/randallyash/spillover), including bugs and
feature requests.
